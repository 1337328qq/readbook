02安全审计结论 P2 安全 · 无投毒风险

审计范围：skill 本体、全部工具脚本、CI 工作流、网页外部引用、正文与长文。未发现 P0 / P1 风险，可放心使用。

未发现 P0（阻断级）风险

  • 无「下载即执行」：没有任何 curl | bash、下载后 eval 的组合
  • 无敏感信息读取外传：不触碰 ~/.ssh、.env、凭证目录
  • 无破坏性命令：全仓库无 rm -rf、无批量删除用户文件的操作
  • 无隐蔽执行：无 nohup、2>/dev/null 配合危险操作的模式

未发现 P1（需关注）风险

  • 无全局依赖安装：脚本内无 npm install -g / pip install；EPUB 工具唯一依赖 marked@18.0.13（npm 官方源、版本锁定、npm ci 安装）
  • 无非官方源：CI 下载的 pandoc 3.11 / typst 0.15.1 / epubcheck 5.4.0 均来自官方 GitHub Releases
  • 元数据正常：description 长度正常、无占位符

隐私注意点（非安全风险，知悉即可）

本部署已主动处理原站检索页会加载 Google Fonts + Google Analytics（gtag）。转载部署时已整段移除 gtag，并移除原站侧栏的第三方广告（Minecraft 服务器）与作者个人微信赞赏码，避免替他人导流、避免访客行为数据汇入他人统计。
正文外链指向期刊/政府网站，check-links.mjs 联网检查时会产生对这些站点的请求（仅 CI 或手动运行时，本部署不含该脚本）。
